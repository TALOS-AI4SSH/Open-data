**Greek Dialect Corpus v1.0** is a **collection of raw text from various Greek dialects**, designed to support research in **Greek linguistics, NLP, and dialectology**.  

It includes material from multiple sources (blogs, websites, theatrical plays, Twitter, translations, etc.), minimally pre-processed and annotated.

## Dataset Overview

- **Dialects covered:**
  - Cypriot Greek  
  - Cretan Greek  
  - Pontic Greek  
  - Northern Greek  
  - Standard Modern Greek (SMG, incl. Twitter data)  
  - Selected material from Modern Greek Wikipedia  

- **Sources:**  
  - Blogs, websites, theatrical plays  
  - Translations of Ancient Greek tragedies/comedies (by Mr. Sfakianakis)  
  - Twitter dataset *SMG_CG* (originally collected by Hanna Sababa)  
  - Folder `all_dialects/` contains a `.zip` archive with **all collected data** with minimal pre-processing
