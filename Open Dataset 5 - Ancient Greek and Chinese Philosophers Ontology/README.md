**Version 1.0 of an ontoterminology** that models **Ancient Greek philosophers**, their **philosophical production**, and their **spatial and temporal positioning**.  

This work builds upon a previous version developed in the context of the [KELKIP Project](https://kelkip.uoa.gr/), expanding to include Chinese philosophers (terms and proper names currently under construction).

## Software Environment
This dataset was built with **Tedi ontoTerminology Editor**, a platform for creating and managing ontoterminologies.  

- **Tedi software** is distributed by the University of Crete (free for academic use).  
- More information: [Tedi ontoTerminology Editor](http://ontoterminology.com/tedi).

## Downloads & Usage
- **Ontology file (RDF/OWL):** Import into [Protégé](https://protege.stanford.edu/) (open access ontology editor) to explore ontology metrics.
- **Visualization:** Load into [VOWL](https://service.tib.eu/webvowl/) to generate graphical visualizations. 
- **SPARQL endpoint:** The `.rdf` file is queryable via a [SPARQL](https://sparql.org/sparql.html) endpoint.  
- **Ontodictionaries (HTML):**
  - **Terms (English):** all | person | period | place | philosophical work | philosophical school  
  - **Terms (Greek):** all | person | period | place | philosophical work | philosophical school  
  - **Terms (Chinese):** *(under construction)*  
  - **Proper Names (English):** all | person | period | place | philosophical work | philosophical school  
  - **Proper Names (Greek):** all | person | period | place | philosophical work | philosophical school  
  - **Proper Names (Chinese):** *(under construction)*  
- **Zenodo:** [10.5281/zenodo.13372136](https://doi.org/10.5281/zenodo.13372136)
