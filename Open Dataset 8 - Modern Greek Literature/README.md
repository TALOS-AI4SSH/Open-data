**Modern Greek Literature v1.0** is a **collection of raw text data from interwar poets and prose writers**, including prose and poetry categorized by date, author, and collection.  
It provides both raw text files and **TEI-compliant XML** encodings for structured use in digital humanities research.

## Dataset Contents

### 📂 Interwar_poetry
- Zipped files containing poetry categorized by **date**, **author**, and **collection**.  
- Collected works per author.  
- Collected works per author in **TEI-compliant XML format**.  

### 📂 Interwar_prose
- Zipped files containing prose categorized by **date**, **author**, and **work**.  
- Works also provided in **TEI-compliant XML format**.
