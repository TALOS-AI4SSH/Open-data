**Version 1.0 of an ontoterminology** (i.e. “a terminology whose conceptual system is a formal ontology” — Roche 2007) that defines and represents the archaeological finds of **T-Pillars in Göbekli Tepe, SE Turkey (ca. 10,000–8,300 BCE)** in a machine-tractable way.

## Software Environment
This dataset was built with **Tedi ontoTerminology Editor**, a software platform for the creation and management of ontoterminologies.  

- **Tedi software** is distributed by the University of Crete (free for academic use).  
- More information: [Tedi ontoTerminology Editor](http://ontoterminology.com/tedi).

## Downloads & Usage
- **Ontology file (RDF/OWL):** Import into [Protégé](https://protege.stanford.edu/) (open access ontology editor) to explore ontology metrics.  
- **Visualization:** Import into [VOWL](https://service.tib.eu/webvowl/) to generate graphical visualizations.  
- **SPARQL endpoint:** The `.rdf` file is queryable via a [SPARQL](https://sparql.org/sparql.html) endpoint (details forthcoming).  
- **Ontodictionaries (HTML):**
  - **Terms:** [all](https://talos-ai4ssh.uoc.gr/wp-content/uploads/2024/08/Gobekli_Tepe_v.1.0_terms_all.en_.html) | [location](https://talos-ai4ssh.uoc.gr/wp-content/uploads/2024/08/Gobekli_Tepe_v.1.0_terms_location.en_.html) | [material](https://talos-ai4ssh.uoc.gr/wp-content/uploads/2024/08/Gobekli_Tepe_v.1.0.terms_material.en_.html) | [type of archaeological find](https://talos-ai4ssh.uoc.gr/wp-content/uploads/2024/08/Gobekli_Tepe_PN_type_of_archaeological_find.en_.html) | [type of relief](https://talos-ai4ssh.uoc.gr/wp-content/uploads/2024/08/Gobekli_Tepe_v.1.0_type_of_relief.en_.html)
